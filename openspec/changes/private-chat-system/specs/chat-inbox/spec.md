## ADDED Requirements

### Requirement: Inbox View
Users must have a central location to see all their active conversations.

#### Scenario: Viewing the inbox
- **WHEN** a user navigates to the "Messages" section
- **THEN** they see a list of all conversations they are part of, ordered by the most recent message.

### Requirement: Unread Indicators
Users should see which conversations have new, unread messages.

#### Scenario: Receiving a new message while in inbox
- **WHEN** a user receives a message in a conversation they are not currently viewing
- **THEN** an "unread" badge or indicator appears next to that conversation in the list.
